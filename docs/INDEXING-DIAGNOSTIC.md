# Indexing diagnostic — second pass

Measured September 24, 2026. `second-pass-crawl.json` contains response headers, TTFB, user agents and redirect chains. Initial production had 50 canonical pages; local second-pass candidate has 52. A later production QA report records deployment validation.

## Severity findings

- P0: **No crawl blocker observed in this sample.** All 162 content/robots/sitemap/login/locale requests across desktop, Googlebot and bingbot user-agent strings returned 200 without detected challenge text. This does not prove real search-engine IP access, continuous uptime or indexing.
- P1: Actual Google/Bing indexed status, chosen canonicals, crawl history and reasons for exclusion are unknown without verified webmaster properties. Use URL Inspection, Pages/Crawl Stats and Bing inspection; compare verified crawler traffic in host logs.
- P1: Incomplete translations intentionally remain noindex. Review translations before advertising reciprocal hreflang; do not treat their exclusion as a defect.
- P2: HTTP www uses two permanent hops (HTTPS www, then HTTPS apex). HTTPS www uses one hop. No loop or redirect to a competing host was observed. Platform-level HTTP-to-HTTPS precedes application redirects; review domain-level redirect configuration if eliminating the extra HTTP hop becomes worthwhile.
- P2: Public pages are dynamically server-rendered (Vercel MISS/private no-store). Header/session behavior protects personalized content; do not apply public shared caching to authenticated output merely to reduce TTFB.
- P2: Contextual linking and real evidence remain more useful work than additional generic landing pages.

## Robots and sitemap
