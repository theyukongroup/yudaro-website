# 30 / 60 / 90-day roadmap

## Days 1–30: verify and measure

Owner: verify business facts, Search Console, Bing and eligible Business Profile; confirm legal/privacy text and optional analytics consent configuration. Submit sitemap, inspect priority pages and collect a nonbranded search baseline. Engineering: monitor crawl/error logs and production vitals, address inherited lint debt, run `npm run seo:audit -- https://yudaro.com` after releases. Editorial: expert review technical pages and begin two highest-fit articles. Sales: define qualified lead, lead source, spam and duplicate handling.

Success criteria: verified properties, sitemap accepted, canonical/noindex behavior checked, no broken conversion flows, event accuracy validated. Track indexed canonical pages where verifiable; do not set guaranteed ranking targets.

## Days 31–60: deepen evidence

Publish 3–4 reviewed articles based on actual search questions and sales objections. Prepare first client-approved case study with measured baseline/outcomes. Review query-to-page overlap and improve titles where impressions warrant it. Verify owned profile links and update consistent NAP. Professionally review translations page by page before enabling indexation and reciprocal hreflang. Diagnose slow real-user templates using field data, reduce unnecessary global CSS/client code only with visual regression coverage.

Success criteria: growing relevant query coverage, useful engagement, accurately attributed qualified consultations and fewer crawl exclusions caused by defects. Compare like-for-like periods rather than promising fixed growth.

## Days 61–90: optimize outcomes

Publish a second verified case study; refresh pricing/scope when actual offers change; refine service/industry paths using qualified leads and sales feedback. Test one CTA or form change at a time, with a measured baseline. Review AI referral/citation observations in Bing and analytics alongside traditional search. Expand content only where demand and expertise justify it. Audit links, schema, business facts and translation parity again.

Success criteria: qualified organic leads, lead-to-consultation rate, page-to-lead conversion, nonbranded impressions/clicks, canonical index coverage, and field LCP/INP/CLS. Record baseline and subsequent values rather than invented targets. No rankings, traffic, citations or revenue outcomes are guaranteed.
