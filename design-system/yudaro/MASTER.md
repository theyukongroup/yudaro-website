## Motion and accessibility

Motion for React with lazy domAnimation features for state transitions. CSS transform/opacity entrances, SVG stroke-dash pulses, sequential workflow outlines, word crossfades, and subtle mouse-only magnetic CTA. IntersectionObserver pauses continuous motion outside the viewport. No canvas-only text, typewriter effects, rotating logos, fake loading, or blocking page transitions. Content renders on the server without JavaScript.

Global pause control, prefers-reduced-motion override, visible keyboard focus, semantic button groups/progress, and keyboard/touch equivalents. On mobile the network becomes a vertical connected sequence, workflow buttons become a list, and pointer magnetism is disabled. Continuous workflow highlighting uses opacity rather than animated box shadows.
