# Weekly SEO and GEO workflow

1. Export Google Search Console queries and pages for the last 28 days; compare with the prior period.
2. Confirm branded impressions/clicks for Nexavoris variants and check the displayed hostname.
3. Isolate positions 8–30 and update `STRIKING_DISTANCE_KEYWORDS.md`.
4. Improve the highest-value existing page: answer completeness, title/description, evidence, and intent—not cosmetic word count.
5. Review pages with impressions but weak CTR; change snippets only when the page can fulfill the promise.
6. Add or repair natural internal links from relevant pages to the designated owner page.
7. Review indexed/not-indexed pages and sitemap status; inspect unexpected canonical selections.
8. Run the fixed GEO prompt set and record mentions separately from linked citations.
9. Record new legitimate backlinks, unlinked brand mentions, and referral quality.
10. Review organic landing → assessment start → assessment complete → registration → roadmap → consultation conversions.

Do not rewrite pages because of age alone. Update when data shows an opportunity, intent or information changed, a material gap exists, or real evidence became available.
